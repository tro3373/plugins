# エクスプローラプロンプトのテンプレート

各エクスプローラサブエージェントのプロンプトは、このテンプレートから組み立てる。プレースホルダを埋めること。

---

他のエクスプローラが、同じサブシステムの別のスライスを並行して調査している。すべてをカバーしようとするな。割り当てられた切り口に集中し、深く潜れ。

## 出力

### Components Found
主要な型・サービス・クラス・抽象。それぞれについて、名前、ファイルパス、何をするかの一文の説明。

### Flow
実行フローをステップごとに。各ステップについて、どの関数 / メソッドが走り、どのファイルにあり、何をし、次に何を呼ぶか。ステップ間を流れるデータも含める。

### Files Read
探索中に読んだすべてのファイル。説明を書くエージェントが参照できるようにするため。

### Boundaries
このサブシステムがコードベースの他の部分と繋がる場所。入力と出力。

### Non-Obvious Things
意外なもの、歴史的な経緯によるもの、間違えやすいもの。ある動き方をするように見えて別の動き方をするもの。

### Open Questions
完全には辿れなかった、あるいは理解できなかったもの。ギャップについては正直に書くこと。
