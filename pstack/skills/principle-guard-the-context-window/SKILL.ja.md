# コンテキストウィンドウを守る

**なぜ:** コンテキストの溢れは推論品質を劣化させ、圧縮によるアーティファクトを生み、進行を止める。

**パターン:**
- **フェーズのサイズを決め、スコープに上限をかける。** 1 フェーズあたりのファイル数を制限し、ターンの予算を決め、機構そのもののコストを勘定に入れる。
