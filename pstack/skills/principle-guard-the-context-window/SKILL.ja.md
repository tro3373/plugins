# コンテキストウィンドウを守る

コンテキストウィンドウはセッション内で有限かつ再生不能である。トークンはすべて、そのコストに見合う価値を持たねばならない。

**なぜ:** コンテキストの溢れは推論品質を劣化させ、圧縮によるアーティファクトを生み、進行を止める。

**パターン:**
- **大きなペイロードを隔離する。** 冗長な出力、スクリーンショット、大きなドキュメントはサブエージェントへ回す。メインのコンテキストが受け取るのは要約であって生データではない。
- **頻繁に使う内容はインラインに置く。** 呼び出しの度に使うテンプレートやリファレンスは、毎回読み込みコストを払う別ファイルではなく skill ファイル本体に置く。
- **フェーズのサイズを決め、スコープに上限をかける。** 1 フェーズあたりのファイル数を制限し、ターンの予算を決め、機構そのもののコストを勘定に入れる。
